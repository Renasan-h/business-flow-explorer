# 画面別テストケース一覧（Playwright）

対象: Business Flow Explorer / Chromium。2026-11-14時点の実装を基準とする。
分類: **表示**=画面の構造・視認性、**動作**=ユーザー操作、**内部**=操作後の状態・保存内容・通信・描画バッファ等。
状態: **自動**= `e2e/screenVerification.spec.ts`、**既存**= `e2e/businessFlow.spec.ts`、**未実装**=追加が必要。
ケースIDをテスト名にも使用する。各ケースは独立したfixtureで実行し、テストの成功はGitHub Actionsの実行結果で判定する。

## 実行方法

```bash
npm install
npx playwright install chromium
npx playwright test e2e/screenVerification.spec.ts --project=chromium
npx playwright test --project=chromium
```

CI: `.github/workflows/ci.yml` の Playwright Chromium E2E ジョブで実行。
**未実装**ケースは合格扱いにしない。画面の表示/操作と内部処理を混同せず、DOM・ダウンロード・fetch・Canvas寸法などを明示的に検証する。
